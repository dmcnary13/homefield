# docs/

Project documentation, distinct from `CLAUDE.md` (which is operational guidance for Claude Code sessions).

- [roadmap.md](roadmap.md) — codebase audit and V1 roadmap: known issues and target architecture, written for a non-technical audience.
- [implementation-plan.md](implementation-plan.md) — technical implementation plan: the phased, sequenced engineering plan derived from the roadmap, including decisions and gaps the roadmap doesn't address (async job architecture, mobile IAP, migration safety, auth strategy).
- [specs/](specs/) — individual implementation specs, one directory per spec (`spec.md`, optionally `chunks.md` + `checklist.md`). See [specs/README.md](specs/README.md) for the convention.

Future planning docs, architecture decision records, and design notes belong here as they're created.
